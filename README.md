## 📅 Day 1 - Linux Fundamentals: Navigation Commands

Started with the basics - learning how to navigate the Linux file system. Here are the essential commands I practiced today:

### Navigation Commands Mastered:

```bash
pwd                 # Print working directory
ls                  # List files

cd ..               # Go up one directory
cd ~                # Go to home directory
clear               # Clear the terminal screen
```


# 🚀 Day 2/90: My Linux & Cybersecurity Learning Journey

## 📅 Day 2 - File Operations: Create, Copy, Move, Delete

Building on yesterday's navigation skills, today I learned how to actually manipulate files and directories in Linux! 💻

### Commands Mastered Today:

**Creating:**
```bash
touch file.txt          # Create files
mkdir dirname           # Create directories
mkdir -p path/to/dir    # Create nested directories
```

**Copying:**
```bash
cp source.txt dest.txt  # Copy files
cp -r dir1 dir2         # Copy directories recursively
```

**Moving/Renaming:**
```bash
mv old.txt new.txt      # Rename files
mv file.txt /path/      # Move to another location
```

**Deleting:**
```bash
rm file.txt             # Delete files (PERMANENT!)
rm -i file.txt          # Delete with confirmation (safer)
rm -r directory         # Delete directories
```

**Viewing Content:**
```bash
cat file.txt            # Display entire file
less file.txt           # View page by page
head/tail file.txt      # First/last 10 lines
tail -f log.txt         # Monitor file in real-time
```
